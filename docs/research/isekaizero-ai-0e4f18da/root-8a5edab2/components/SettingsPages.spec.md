  2. Card "Connection" (accordion chrome, open): fields (label `font-size:12px; font-weight:600; color: rgba(255,255,255,0.7); margin-bottom:6px`; input `height:44px; width:100%; padding:0 14px; border-radius:12px; background: rgb(47,51,80); border:1px solid rgba(167,185,255,0.5); font-size:14px; color:#fff; outline:none; focus:border-color rgb(167,185,255)`):
     - "API key" (type password with an eye toggle button inside, lucide `Eye`/`EyeOff` 18px), helper `font-size:11px; color: rgba(255,255,255,0.45)` "Stored only in this browser (localStorage). Never sent anywhere except your provider." and a link "Get a NanoGPT key ›" (preset.keysUrl, opens new tab) `color: rgb(167,185,255); font-size:12px`.
     - "Chat base URL" (text), "Image base URL" (text; helper "NanoGPT serves images at https://nano-gpt.com/v1").
     - Row of two buttons: GradientButton "Test connection" (calls `GET /api/providers/models` with `providerHeaders`; shows result line: success `color: rgb(128,202,16)` "Connected · {n} text models · {m} image models", failure `color: rgb(255,87,71)` with the error message) and an outlined button "Clear key" (`.iz-border-button` ring, inner `background: rgb(45,49,92)`, `height:44px; border-radius:22px; font-size:14px; font-weight:500`).
  3. Card "How it works" (info note style): three bullet lines `font-size:13px; line-height:19px; color: rgba(255,255,255,0.7)`: "Chat uses POST {base}/chat/completions with streaming.", "Scene images use POST {imageBase}/images/generations (OpenAI-compatible).", "Model lists come from GET {base}/models and GET {base}/image-models when available."
- **Models tab**: two `SelectRow`s (site's row style from the image generation page: `height:49px; flex row; justify-content:space-between; align-items:center; cursor:pointer`; left col title `font-size:18px; font-weight:600` + sub `font-size:14px; color: rgba(255,255,255,0.5)`; right col value `font-size:16px; color: rgb(160,160,160); text-align:right` + sub `font-size:12px; color: rgba(255,255,255,0.4)`; lucide `ChevronRight` 20px):
  - "Text model" / "Used for every new chat" → value = current textModel; clicking opens an inline searchable list (input `height:40px` + scrollable list `max-height:320px` of rows `padding:10px 12px; border-radius:10px; hover bg rgba(255,255,255,0.06)` showing name, id `font-size:11px; color: rgba(255,255,255,0.45)`, and price `font-size:11px; color: rgba(255,255,255,0.6)` "{in}/{out} $ per M" when known).
