# ImageGeneration Specification (/creation/generate-image)

## Overview
- **Target files:**
  - `src/components/sites/isekaizero-ai-0e4f18da/image-generation/ImageGenerationPage.tsx` (client)
  - `src/components/sites/isekaizero-ai-0e4f18da/image-generation/ImageModelPicker.tsx` (modal/sheet listing image models)
  - `src/components/sites/isekaizero-ai-0e4f18da/image-generation/use-image-generation.ts` (calls `POST /api/images/generate`)
- **Screenshots:** `_tmp_genimage2.png` (form + empty state), `image-generation-model-picker-1440.png` (model picker sheet)
- **Interaction model:** click-driven form. "Generate Image" → POST `/api/images/generate` with `providerHeaders(settings)` and `{ model, prompt, size }`; result renders in the right pane; history strip below.
