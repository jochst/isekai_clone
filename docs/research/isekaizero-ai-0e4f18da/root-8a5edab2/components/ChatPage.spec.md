## Data model (chat-store)
```ts
createChatSession(storyline: Storyline, opts?: { playerName?: string; scenarioIndex?: number }): ChatSession
// first message = { role: "assistant", content: storyline.opening } (scenario summary appended when scenarioIndex given)
// settings default: { modelId: "auto", responseLength: "medium", temperature: "medium", reasoning: false, perspective: "2nd", autoIllustrate: <ProviderSettings.autoIllustrate>, illustrationModel: "default", illustrationPerspective: "third" }
useChatSessions(): ChatSession[] (sorted by updatedAt desc)
useChatSession(id): [ChatSession | undefined, (patch: Partial<ChatSession> | ((s: ChatSession) => ChatSession)) => void]
addUsage({ tokensIn?, tokensOut?, images?, cost?, messages? })
```
Persist on every change (debounced 150ms). Cap stored images: keep image `url` (data URLs can be large — if a data URL exceeds 1.5MB, store it in memory only and mark `status:"done"` with `url` kept in a module-level Map so a reload shows a "regenerate" placeholder).

## Prompting (prompting.ts)
- System prompt: "You are the narrator and every non-player character of the interactive story "{title}". Setting: {plot}. Characters: {name} — {role}. {persona} (appearance: {appearance}) … The player is {playerName}. Write in {perspective} person, present tense, {responseLength → 'about 80 words' | 'about 180 words' | 'about 320 words'}. Never speak or act for the player. Stay in character; keep dialogue in quotes and actions in italics using *asterisks*. End each reply at a moment that invites the player to act." Perspective 2nd = "second person ('you')".
- Scene prompt (for images): "Anime illustration, {illustrationPerspective === 'pov' ? 'first-person POV of the player' : 'cinematic third-person shot'}, of the following scene from "{title}": {last assistant message, trimmed to 600 chars}. Characters present: {names+appearance for characters mentioned in the last 3 messages}. Style: detailed anime key visual, dramatic lighting, high quality, no text, no watermark." Then optionally prepend the enhanced version via the text model when `enhance` is true (POST /api/chat non-stream with instruction "Rewrite as a concise Stable-Diffusion-style prompt ≤ 70 words").
- Temperature map: low 0.5, medium 0.9, high 1.1, max 1.3. `max_tokens`: short 220, medium 450, long 800.
- `streamChat({ settings, model, messages, onDelta, onDone, signal })` → POST `/api/chat` with `providerHeaders(settings)`, parse SSE lines `data: {json}` → `choices[0].delta.content`; ignore `[DONE]`; accumulate `usage` if present in the final chunk.
- Model resolution: `settings.textModel` from ProviderSettings when `chat.settings.modelId === "auto"` or when the selected id is a BYOK id; if the selected id is a platform catalog id, send the catalog row's `model` string (the provider may or may not serve it — errors surface inline).

## Send flow
1. Append user message; append assistant placeholder `{ streaming:true, content:"" }`; call `streamChat`; append deltas; on done set `streaming:false`, `addUsage`.
2. If `autoIllustrate` (chat setting overrides provider setting) and an image model is configured → immediately create a `SceneImage {status:"generating"}` on that assistant message and POST `/api/images/generate` with `buildScenePrompt` + `size: settings.imageSize`; on success set `url/status:"done"`, `addUsage({images:1, cost})`; on error `status:"error"`.
3. Manual "Illustration" button does step 2 for that specific message (append a new SceneImage; multiple allowed).
4. Errors from `/api/chat` → replace the placeholder with an error bubble `background: rgba(255,87,71,0.12); border:1px solid rgba(255,87,71,0.4)` + "Retry".
5. Retry = remove last assistant message and resend the previous user turn.
